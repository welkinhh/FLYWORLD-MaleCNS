# FLYWORLD — Windows

1. 从 [GitHub Releases](https://github.com/welkinhh/FLYWORLD-MaleCNS/releases/latest) 下载并解压 Windows x64 压缩包。
2. 保持 `FLYWORLD.exe` 和 `brain_service.exe` 在同一目录，双击 `FLYWORLD.exe` 启动。

运行游戏无需安装 Godot 或 Python。首次连接大脑时需要联网下载神经模型数据；未连接大脑也可以游玩生态模拟。

## 操作

- 点击果蝇查看个体状态和事件。
- 选择“放糖”或“放天敌”后点击场景放置；选择“删除天敌”后点击蜘蛛移除。
- 顶栏可暂停、重新开始、调整倍速、温度、湿度和光照。
- 滚轮缩放，右键复位视角，Esc 取消当前工具。

脑信号为神经连接组驱动的计算模拟，不是活体神经记录。
